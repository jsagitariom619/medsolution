# Módulo de Enfermería - Med Solution

El módulo de enfermería agrega una interfaz de gestión para 6 especialidades:
- Inyectables
- Curaciones
- Nebulizaciones
- Anticonceptivos
- Sueroterapia
- Fisioterapia

## Incluye
- Navegación por pestañas por especialidad
- Modal unificado para crear/editar registros
- Tabla con acciones CRUD
- Filtros por fecha, paciente, enfermera y búsqueda global
- 2 registros de demostración por especialidad (12 en total)
