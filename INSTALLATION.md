# Instalación y configuración

## Requisitos
- Navegador moderno
- Servidor estático opcional para pruebas locales

## Ejecución local
1. Abrir la carpeta del proyecto.
2. Servir el contenido con cualquier servidor estático (opcional).
3. Ingresar a `index.html`.
4. Acceder a `pages/nursing.html` desde la navegación.
